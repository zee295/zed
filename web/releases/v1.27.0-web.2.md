Zed Web preview based on upstream Zed v1.27.0.

## Changes

- Guard browser foreground task polling against reentrant GPUI application borrows. ACP startup and session updates wait for the current borrow to end instead of panicking.
- Apply the guard through the shared executor, including normal, priority, and idle tasks, without agent-specific branches. Production desktop scheduling is unchanged.
- Add regression tests for initial task execution and tasks waking during an active borrow, and document the guard for future upstream merges.

## Verification

The two new borrow regression tests reproduced the panic before the fix and passed afterward. The local production build, all 404 GPUI tests, all five shared ACP runtime tests, and all 19 Chromium browser tests passed. Two GPUI benchmarks were ignored.

The broader agent-server suite passed 187 tests, with one ignored and two failures in the existing native Tree-sitter settings-migration shim. Live GPT-agent startup still needs confirmation on the deployed build; the browser tests do not authenticate real agent accounts. Firefox-specific issue #3 remains open pending verification on an environment with working Firefox WebGL support.

The release workflow runs backend tests, the WASM compile check, the clock audit, and memory-patch tests before building both Docker architectures. Versioned images and the GitHub release are published only after both architecture builds succeed. Publishing this release does not redeploy staging.
