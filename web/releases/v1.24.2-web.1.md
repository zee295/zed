Zed Web preview based on upstream Zed v1.24.2.

## Changes

- Merge upstream stable v1.24.2 and adapt its GPUI, settings, dependency, and extension-store changes for the browser.
- Preserve live agent profile and permission settings, Markdown list continuation in the composer, server-side ACP installation, and Git refresh notifications.
- Preserve browser input, mobile resizing, terminal, and reentrant frame handling fixes.

## Verification

Local production build completed. All 83 backend tests, 372 GPUI tests, and 12 browser regressions passed; two GPUI benchmarks were ignored. Browser coverage includes Git refresh, profile creation and live settings, composer lists, uploads, reconnects, mobile resizing, input bursts, and pasted images.

The release workflow runs backend tests, the WASM compile check, the clock audit, and memory-patch tests before building both Docker architectures. Versioned images and this release are published only after both architecture builds succeed.

The native settings migration test remains affected by the existing Tree-sitter shim; browser settings and composer behavior are verified separately.
